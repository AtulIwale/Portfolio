# Procurement & Subcontracting

One shared dataset across requirements, implementation planning, analysis and the working app. **5,000 synthetic records.** One purchase order or subcontract work order.

| Area | What was done |
| --- | --- |
| [Business Analysis](business-analysis.md) | Mapped requisitions, order types, approvals and invoice-matching requirements. |
| [Project Management](implementation.md) | Planned supplier migration, order configuration, UAT and implementation costs. |
| [Data Analysis & Data Science](data-analysis.md) | Analysed order values, delivery outcomes and procurement status patterns. |
| [Machine Learning & AI](machine-learning-ai.md) | Trained a delivery-risk model and built an order review app. |

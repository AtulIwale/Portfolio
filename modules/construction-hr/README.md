# Construction HR

One shared dataset across requirements, implementation planning, analysis and the working app. **5,000 synthetic records.** One employee-month attendance summary for 500 employees across 10 months.

| Area | What was done |
| --- | --- |
| [Business Analysis](business-analysis.md) | Mapped attendance, leave, overtime approvals and payroll handoffs. |
| [Project Management](implementation.md) | Planned employee migration, attendance setup, UAT and rollout costs. |
| [Data Analysis & Data Science](data-analysis.md) | Analysed worked days, attendance statuses and clerical corrections. |
| [Machine Learning & AI](machine-learning-ai.md) | Trained a record-quality model and built an attendance review app. |

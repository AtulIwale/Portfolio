# Accounts Receivable & Accounts Payable

One shared dataset across requirements, implementation planning, analysis and the working app. **5,000 synthetic records.** One AR or AP invoice with settlement allocations.

| Area | What was done |
| --- | --- |
| [Business Analysis](business-analysis.md) | Defined invoice matching, settlement allocation and aging controls. |
| [Project Management](implementation.md) | Planned balance migration, finance configuration, UAT and cutover. |
| [Data Analysis & Data Science](data-analysis.md) | Analysed invoice values and settlement states across AR and AP. |
| [Machine Learning & AI](machine-learning-ai.md) | Trained a late-settlement model and built an invoice review app. |

# Motion Design Skill

The goal is to make the portfolio feel polished, premium, and human-designed.

Use motion sparingly and intentionally.

Prioritize:
- hero text reveal
- subtle section entrance animations
- staggered project-card reveals
- refined hover states
- image hover movement
- navigation transitions
- smooth state changes
- subtle scroll-based motion
- premium easing and timing
- responsive performance

Avoid:
- excessive movement
- bounce-heavy animation
- spinning
- constant floating elements
- unnecessary parallax
- long animation durations
- animation on every element
- effects that make the site feel like a demo

Motion should support hierarchy and storytelling.

Prefer one memorable motion idea over many small random effects.

For each animation:
- keep duration restrained
- use natural easing
- avoid blocking interaction
- make sure it works on mobile
- respect prefers-reduced-motion

When reviewing an existing page:
1. identify where motion would add value
2. remove motion that feels decorative or repetitive
3. improve timing consistency
4. preserve performance
5. ensure motion matches the overall visual identity

Do not redesign the site unless asked.

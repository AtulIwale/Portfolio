# Visual Assets Skill

The goal is to make the portfolio feel professionally art-directed rather than AI-generated.

Images must feel intentional and connected to the person's work and story.

Prioritize:
- strong hero imagery when appropriate
- high-quality project screenshots
- image-led project case studies
- editorial cropping
- varied image compositions
- close-up/detail shots
- contextual mockups only when useful
- subtle texture and depth
- images that support the portfolio narrative

Avoid:
- generic stock photography
- random abstract 3D blobs
- generic AI-generated people
- overused gradient spheres
- fake dashboard mockups
- decorative images with no purpose
- repeating the same image size and layout everywhere

For project sections:
- choose a strong primary image
- add supporting detail images if available
- vary orientation and crop
- use full-bleed imagery where appropriate
- create visual rhythm between text and imagery

If image generation is available:
- generate visuals that match the site art direction
- avoid obvious AI artifacts
- avoid generic prompt aesthetics
- keep lighting, composition, and tone consistent

If real project screenshots are available, prefer them over generated images.

When reviewing the website:
1. identify sections that feel visually empty
2. identify weak or generic imagery
3. improve image scale, crop, and placement
4. preserve loading performance
5. ensure images support the user's work rather than distract from it

Do not redesign the whole website unless asked.

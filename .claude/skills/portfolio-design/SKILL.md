# Portfolio Design Skill

You are helping improve a personal portfolio website.

The goal is to make it feel:
- premium
- modern
- minimal
- personal
- visually distinctive
- professional on desktop and mobile

Focus on:
- strong typography
- clear visual hierarchy
- good spacing
- a strong hero section
- polished project sections
- clean navigation
- subtle animation
- excellent mobile responsiveness

Avoid:
- generic SaaS styling
- too many gradients
- excessive glassmorphism
- too many rounded cards
- unnecessary animations
- cluttered layouts

Before making major changes:
1. Inspect the existing website.
2. Understand the current content and structure.
3. Suggest one clear design direction.
4. Wait for my approval before making major visual changes.

When implementing:
1. Improve typography first.
2. Improve spacing and layout.
3. Improve the hero section.
4. Improve project presentation.
5. Improve navigation.
6. Improve mobile layout.
7. Keep all existing content and functionality unless asked otherwise.

After changes:
- review visual consistency
- review spacing
- review typography
- review responsive behavior
- review hover states
- review mobile usability
- fix anything that still feels generic or unfinished
